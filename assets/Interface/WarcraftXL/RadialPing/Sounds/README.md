# Optional radial-ping sounds

The client module looks for these optional files in this directory:

- `OnMyWay.ogg`
- `Attack.ogg`
- `Warning.ogg`
- `Assist.ogg`

The source addon did not contain the sound binaries. Missing files are safe: the 3.3.5 client
silently skips them. Add matching assets here later without changing the module code.
