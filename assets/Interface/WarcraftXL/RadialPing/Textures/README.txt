Place the following two BLP texture files in this folder:

    uipingsystem2x.blp
    uiradialwheel.blp

Final paths (the addon expects them at exactly these locations):

    Interface\AddOns\RadialPing\Textures\uipingsystem2x.blp
    Interface\AddOns\RadialPing\Textures\uiradialwheel.blp

Without these files the wheel and the world ping markers will be invisible.
